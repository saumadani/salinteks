# SalinTeks

Website latihan menyalin teks untuk pembelajaran TIK.

## Tentang

SalinTeks merupakan website latihan sederhana yang digunakan untuk melatih kemampuan peserta didik dalam menyalin dan mengetik teks.

## Teknologi

- HTML
- CSS
- JavaScript

## Penggunaan

Website dapat dibuka melalui browser dan digunakan sebagai media latihan TIK.
